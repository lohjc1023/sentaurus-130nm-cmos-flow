What is happening, and why
Reading the drawing. The cross-section is to scale in both directions (1.2 × 0.85 µm shown), except that films thinner than about 6 nm — the 1.5 nm gate oxide, the 2 nm screen oxide, the STI liner — are drawn thicker so they stay visible. Real values are always given in the command panel.

What this is and is not. The geometry is reconstructed from the etch, deposition and mask statements in the command file, not read back from a TDR file, so a real level-set solution will differ in detail — particularly at corners, at the divot and in the exact spacer profile. Doping regions are schematic, drawn to show where each implant lands rather than to represent a computed concentration.

Assumptions. Workbench parameters are taken as @Domain@ = NMOS, @Lgate@ = 0.13 µm, with fp = 1.0, FastMode = 0 and debug = 0, so every implant and diffuse runs and the WriteBND boundary dumps are skipped. The active-area width and contact placement are taken from the design rules in the file (IsoPitch 0.345, PolyPitch 0.32) since the layout file CMOS130_lyt.mac was not available.
